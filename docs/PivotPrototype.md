## 1. 背景与目标

用 Handsontable 实现一个**类透视表的可编辑表格**，业务原型：**组织（行树）× 科目（行树）× 期间（列树）→ 指标值**。

- 行方向：**组织**（如 华润微电子集团 → 本部 / 华晶公司）、**科目**（如 费用汇总 → 费用-办公费 / 电费 / 水费）两条树，**行 = 两树的全节点交叉**（父节点常驻、带汇总值）。
- 列方向：**期间**（Q1 / Q2 → 1、2、3 月）+ **指标尾**（预算数 / 实际数 / 完成率…）；期间结构可**对称/非对称**（各分支子项一致或不一致）。
- 值 = (组织节点, 科目节点, 期间列节点, 指标) 四元组；由后端按规则聚合，前端零计算。
- 保留：后端分摊、保存制（批量提交+脏标记）、增量更新（delta 打补丁）、版本冲突、单元格历史、按需分块扩展、多格式属性列。

## 2. 表格结构（v8 定稿）

### 2.1 整体布局（demo 全展开）

```
组织(树)  | 组织属性 | 科目(树)  | 科目属性 |        期间 Q1（对称 1、2、3月）        |       期间 Q2       | ...
                                   |  1月              |  2月              |  3月    | ...
                                   | 预算|实际|完成率  | 预算|实际|完成率  | 预算|实际|完成率 | ...
▾ 华润微电子集团 | 集团属性 | ▾ 费用汇总  | 属性   | 300|350|85% | ...（行= 集团×费用汇总）
                |          |   办公费    |       | 100|120|80% | ...（行= 集团×办公费）
                |          |   电费      | ...   （行= 集团×电费）
                |          |   水费      | ...
▾ 华润微电子本部 | 本部属性 | (科目 4 行同构) ...
▸ 华晶公司      | 华晶属性 | ...
```

- **行 = 组织树全部节点 × 科目树全部节点 的笛卡尔积**（含 (集团, 费用汇总) 这类"父×父"合计行）。demo：3 组织节点 × 4 科目节点 = **12 行**（全展开）。
- 行排序：组织树先序为外，科目树先序为内 → 每个组织节点的行块连续，块内依次是它的全部科目节点行。
- 父节点常驻：行集包含所有父节点；父行的值 = 其后代叶子按后端规则的聚合。

### 2.2 行区（每维度一列，单列树 + 合并）

- 每个**行维度**一列树（组织列、科目列），层级用**缩进 + 组内合并**表达：
  - 组织节点行块（= 该组织节点的全部科目行，如集团块 4 行）内，组织列**组首行显示标签并跨块合并**（`mergeCells`），块内其余行留白；
  - 科目列内每行一个科目节点（块内科目各占一行，费用汇总缩进 0 带图标，办公费/电费/水费缩进 1），父子关系 = 缩进 + 图标；
- **属性列**：每个行维度配一个属性列（demo：组织属性、科目属性），位置可配置（默认紧跟其维度列：`组织 | 组织属性 | 科目 | 科目属性`）。属性**属于维度节点**，与其维度列**同步合并**（同一行块区间）；可编辑，格式：日期（ISO `YYYY-MM-DD` 原生选择器）/ 文本 / 下拉（选项），逐节点配置。
- **折叠**（仅维度层）：折叠组织节点 → 隐藏其**后代组织节点**的行块（含其中全部科目行），保留自身行块；折叠科目节点 → 在**所有**组织块中隐藏该科目**后代节点**的行，保留该科目自身的行。折叠语义 = 保留节点自身行。

### 2.3 列区（维度层可折叠 + 指标尾固定）

- 列结构 = **维度层（期间树，可折叠）** + **指标尾（固定叶子列，永不折叠）**：
  - demo 维度层：期间 → Q1、Q2 → 各 1、2、3 月（**对称**）；非对称例：Q1 → 1、2 月，Q2 → 2、3 月（分支形状自由，**Q1 的 2月 与 Q2 的 2月 是独立节点**，key 必须带父路径，如 `期间:Q1:2月`）。
  - demo 指标尾：预算数 / 实际数 / 完成率，**挂在每个月份叶子下**。
  - 值列全展开（对称 demo）= 2 Q × 3 月 × 3 指标 = **18 列**；值列 key = 完整路径，如 `期间:Q1:1月:预算数`。
- **表头**：3 层 `nestedHeaders`（Q 层 / 月层 / 指标层），指标列名在同一月份内横向排列。
- **折叠规则（关键，用户确认）**：
  - **只有"维度层"节点可折叠**——即其子级仍是维度层节点的节点（Q1 的子级是月份 → Q1 可折叠）；
  - **指标层永不折叠**；**子级为指标层的维度节点（月份）也不单独折叠**；
  - **折叠形态（方案 a）**：Q1 折叠后 → 隐藏月份层，保留指标层，显示 **3 个聚合列**：`预算数(合计) | 实际数(合计) | 完成率(合计)`（各 = 该 Q 下所有月份按指标的聚合）；列组头折叠状态用 `▾/▸` 提示。
- 折叠列组后的列结构、nestedHeaders、columns 全部随折叠状态重建（引擎已有机制）。

## 3. 行/列模型配置化（通用性要求）

行维度、列维度均为**配置驱动**：

```ts
// 行维度（可多个，顺序即列顺序；层级深度任意）
ROW_DIMS = [
  { key: 'org', label: '组织', tree: 华润微电子集团 → [华润微电子本部, 华晶公司],  // 2 层
    attr: { 位置: 紧跟其后, 每节点属性 文本/日期/下拉 可配 } },
  { key: 'acc', label: '科目', tree: 费用汇总 → [费用-办公费, 费用-电费, 费用-水费],
    attr: { ... } },
]

// 列维度：维度层（可多个层级、可对称/非对称、可折叠）+ 指标尾
COL_CONFIG = {
  dims: [ { key: 'period', label: '期间', levels: [Q1/Q2…] → [月…] } ],  // 维度层
  metrics: ['预算数', '实际数', '完成率'],   // 指标尾，挂在最末维度层节点下
}
```

- demo 提供一个**对称/非对称切换**（Q1/Q2 的子月集合不同），验证列树任意形状。
- 折叠可用性由配置/结构判定：节点可折叠 ⟺ 有子级 且 子级属于维度层。

## 4. 数据与值语义

### 4.1 明细（源数据）

```ts
interface SourceRecord {
  orgLeaf: string;    // 组织叶子：华润微电子本部 / 华晶公司
  accLeaf: string;    // 科目叶子：费用-办公费 / 费用-电费 / 费用-水费
  period: string;     // 期间叶子（带父路径）：期间:Q1:1月
  metric: string;     // 指标：预算数 | 实际数 | 完成率
  amount: number;     // 值（唯一值源，可编辑）
}
```

demo 对称期间：2 组织叶 × 3 科目叶 × 6 期间叶 × 3 指标 = **108 条**（确定性 PRNG 生成）。

### 4.2 聚合与矩阵

- 值(行对 `(orgNode, accNode)`, 列节点 `colNode`) = Σ 明细：`orgLeaf ∈ orgNode 子树` 且 `accLeaf ∈ accNode 子树` 且 `期间叶子 ∈ colNode 子树`（指标 = colNode 路径末端的指标）。
- 行 key（矩阵第一维）= `org:华润微电子集团|acc:费用汇总` 形态（行节点对）；列 key 带完整路径。
- 后端 `matrix` 覆盖：所有行节点对 × 需要展示的列节点（Q1 折叠时 = `(行对, Q1:预算数)` 等指标级聚合节点）。
- 规则引擎按**指标**配置（demo：全部可加 SUM；完成率也按 SUM 处理，因为"指标列都可编辑"，无只读派生列）。

### 4.3 编辑 / 分摊（沿用 v7 全部机制）

- **所有值列可编辑**；叶子×叶子×叶子×指标 格 = 直接改明细；任何含父节点的格 = 记录意图值，保存时后端分摊到其覆盖明细集。
- 分摊、取整（最大余数法 Σ==N）、空集拒绝、增量重算闭包、409 冲突、历史记录：**逻辑不变**，只是叶子维度从二元扩展为四元。
- 属性编辑、保存制、脏标记（方案 B：等值过滤 + 基准比较消脏）、`[pivot-edit]`/`[pivot-save]` 打印：沿用。

## 5. 后端接口契约（字段全解 + 数据拆分逻辑）

> 前端零计算：后端下发"结构 + 值源 + 全量聚合矩阵"，前端查表渲染；
> 保存制：批量提交编辑 → 后端分摊/重算 → 返回增量 delta；版本乐观锁。

### 5.1 数据是如何拆分的（核心逻辑）

表格展示的是一个"虚拟立方体"：**组织树(3 节点) × 科目树(4 节点) × 期间树(8 节点) × 指标(3)** 的每一层组合都可能是格子。真实存储只落最细一层，其余全部是"看视图"：

```
结构层（meta，后端下发）：
  组织树: 华润微电子集团 → [本部, 华晶]          深度 2（父+子）
  科目树: 费用汇总       → [办公费, 电费, 水费]   深度 2
  期间树: Q1/Q2          → [1月,2月,3月…]         深度 2（对称/非对称由结构表达）
  指标尾: [预算数, 实际数, 完成率]（挂每个期间叶子下）

存储层（records，只存最细）：
  一条 = (组织叶, 科目叶, 期间月, 指标) → amount      demo：2×3×6×3 = 108 条

展示层（matrix，后端把 records 汇总到每一级）：
  格 = (组织节点 × 科目节点) 行对 × (期间节点 : 指标) 列
  任意格的值 = Σ 属于"该行对子树 ∩ 该期间节点子树"且指标一致的 records
  demo：12 行对 × (2Q+6月=8 期间节点) × 3 指标 = 288 项
```

- **父级不存值**：一条 record 会"参与"多个矩阵格——参与数 = 其组织祖先数 × 科目祖先数 × 期间祖先数。例：`(本部, 办公费, Q1:1月, 预算数)` 参与 3(本部/集团) × 2(办公费/费用汇总) × 2(1月/Q1) = **12 个格**。
- **恒等式**：(集团,费用汇总,Q1,预算数) = Σ(本部/华晶 × 办公费/电费/水费 × Q1 三个月 × 预算数 记录)；Q1 折叠聚合列 `period:Q1:预算数` 的值 = 该 Q 各月同指标之和。
- 编辑父格 = 后端把新值**分摊拆分**回其覆盖的 records（按比例/平均 + 最大余数取整，Σ==编辑值）；编辑叶子格 = 直改该 record。

### 5.2 接口字段全解（`[pivot-backend]` dump 同构）

**① rowDims —— 行维度定义（数组，每个行维度一个对象；demo 2 个：org/acc）**

| 字段 | 含义 | 示例 |
|---|---|---|
| `key` | 维度唯一标识（key 前缀、属性列引用） | `"org"` / `"acc"` |
| `label` | 展示名（列头） | `"组织"` |
| `nodes[]` | 维度树（递归） | 见下 |

| nodes 内字段 | 含义 | 示例 |
|---|---|---|
| `key` | **全路径节点标识** = `维度key:路径标签`（同层同名也要带父路径区分） | `"org:华润微电子集团"`、`"org:华润微电子集团:华润微电子本部"` |
| `label` | 单元格显示文本 | `"华晶公司"` |
| `children[]` | 子节点；**空 = 叶子**（叶子才可能有 records） | — |

**② colConfig —— 列配置**

| 字段 | 含义 | 示例 |
|---|---|---|
| `periods[]` | 期间树（维度层，可折叠；结构=后端给，对称/非对称在此表达） | `{ key:"period:Q1", label:"Q1", children:[{key:"period:Q1:1月",label:"1月",…}] }` |
| `metrics[]` | **指标尾**（字符串列表；挂在每个期间叶子下，永不折叠） | `["预算数","实际数","完成率"]` |

值列 key = `期间节点key:指标`，如 `"period:Q1:1月:预算数"`；Q 折叠聚合列 key = `"period:Q1:预算数"`。

**③ attrs —— 属性（holder → Attr）**

| 字段 | 含义 | 示例 |
|---|---|---|
| holder（对象 key） | 属性作用域：组织属性 = 组织节点 key；科目属性 = `组织key\|科目key`（方案 2，各组织块独立） | `"org:华润微电子集团"`、`"org:…本部\|acc:…办公费"` |
| `format` | `'none'`(空只读) \| `'dropdown'` \| `'date'` \| `'text'` | `"date"` |
| `options` | dropdown 选项（仅 dropdown） | `["一级责任单位",…]` |
| `value` | 属性当前值（date 为 `YYYY-MM-DD`；可编辑） | `"2024-05-01"` |

**④ records —— 明细（值源，只存叶子×叶子×叶子×指标）**

| 字段 | 含义 | 约束 |
|---|---|---|
| `orgKey` | 组织**叶子**节点 key | 必须是叶子 |
| `accKey` | 科目**叶子**节点 key | 必须是叶子 |
| `periodKey` | 期间**月**叶子 key | 必须是叶子（月） |
| `metric` | 指标 | ∈ metrics |
| `amount` | 金额（源值） | 分摊改写它 |

**⑤ matrix —— 聚合矩阵（前端展示唯一数据源）**

每条 = `[行对key, 列key, 值]` 三元组：

| 元素 | 含义 | 示例 |
|---|---|---|
| 行对 key | `组织节点key \| 科目节点key`（**可为父节点** → 父×父合计行） | `"org:华润微电子集团\|acc:费用汇总"` |
| 列 key | `期间节点key:指标`（期间节点可为 Q 或月；**Q 级 = 折叠聚合列，后端必须给**） | `"period:Q1:预算数"` |
| 值 | 按该指标规则（求和/加权/自定义）聚合 | `900` |

**⑥ version —— 乐观锁**：保存时回传，不一致 → 409 → 前端全量重拉。

**⑦ 保存请求 changes[]**

| 字段 | 含义 | 示例 |
|---|---|---|
| `kind` | `'value'`（值格）\| `'attr'`（属性格） | `"value"` |
| `row.key` | 值格 = 行对 key；属性格 = **holder** | `"org:…集团\|acc:费用汇总"` |
| `row.path` | 该 key 的路径 key 数组（溯源/日志） | `["org:…集团","acc:费用汇总"]` |
| `col.key` | 值格 = 列 key；属性格 = `attr:org`/`attr:acc` | `"period:Q1:预算数"` |
| `col.path` | 路径拆分 | `["period:Q1","预算数"]` |
| `oldValue` / `newValue` | 改前/改后（属性为字符串，值为数字） | `900` / `1200` |

**⑧ 保存响应 SaveDelta**

| 字段 | 含义 |
|---|---|
| `version` | 新版本号 |
| `changedCells[]` | `[行对key, 列key, 新值]`——**只含值真正变化**的矩阵格（闭包 = 被改明细的组织祖先×科目祖先×期间祖先×指标） |
| `changedLeaves[]` | `[明细key, 明细key, 新金额]`——被分摊改写的记录（key = `org叶\|acc叶\|period月\|指标`） |

**⑨ 历史条目 CellHistoryEntry**：`rowKey/colKey`（同保存载荷标识）、`oldValue/newValue`、`operator`（操作人）、`timestamp`、`type`（`manual` 手动 / `allocated` 分摊写入）、`affectedLeaves`（影响记录数）、`version`。

### 5.3 保存/分摊链路（数据如何"拆"回去）

```
用户编辑 (集团,费用汇总,Q1,预算数) = 1200（原 900）
  → 后端 leafSet = 覆盖记录：本部/华晶 × 办公费/电费/水费 × Q1:1/2/3月 × 预算数（18 条）
  → 按策略分摊：new_i = 1200 × old_i/900（比例）或均分；最大余数取整 ⇒ Σ=1200
  → 增量重算受影响闭包（这些记录的组织/科目/期间祖先 × 指标 = 去重后的格集合）
  → changedCells 只含旧值≠新值的格；changedLeaves = 被改的 18 条
  → 历史写每个 changedCell 一条（聚合格 affectedLeaves=18, type='allocated'）
```

## 6. 前端渲染模型要点（在 v7 基础上调整）

1. 可见行 = 行对列表：外循环组织树（先序、跳过折叠节点的后代），内循环科目树（先序、跳过折叠节点的后代）。
2. 行数据对象字段：`d_org / d_acc`（维度列标签，组首行有值、其余 ''，配合合并）、`a_org / a_acc`（属性列值，同理）、各值列 `colKey → 值`。
3. 合并区间：组织节点行块跨科目行数（属性列镜像同区间）；科目节点在组织块内各占一行（span=1，不合并）；折叠后行块收缩。
4. 列重建：按 COL_CONFIG 生成 nestedHeaders（Q/月/指标 3 层）与值列（Q 折叠 → 指标聚合列），随折叠状态重建；**折叠可用性**：Q 层可折叠、月/指标层不可（点月层表头无反应）。
5. 单元格 meta：行对 key/路径、列节点 key/路径、脏判定、可编辑判定（值列全部可编辑；维度/属性按规则）。
6. `cells` 回调返回编辑器类型：值列（数字）、属性列（按节点格式 + 显式 `renderer`，防 type 覆盖，见 v7 NOTES）。
